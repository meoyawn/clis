# Getmatch CLI

- Salary research stays read-only; use observed native endpoints and preserve units, sample sizes and provenance.
- Explicit profile exports and reviewed native applications may include personal fields; save private files mode 0600. Never include personal fields in aggregate salary output/caches, or output cookies/session tokens. Keep fixtures synthetic and captures outside Git.
- Never upload a PDF for an application. It reparses and replaces the shared profile, mistakes projects for employment, and can lose language/maturity/evidence links. Use the general Russian profile plus a tailored cover letter. Historical PDF packages remain immutable and read-only verification stays supported.
- Apply only under the user's application instruction after the required tailoring/review. A checksum binds the exact package; it does not grant consent. Never submit live applications to test code. POST once, retain the receipt and independently read status; inspect uncertain outcomes before retrying.
- One foreground command per account at a time. Reuse HTTP connections within that process and close them on exit; no daemon or connections retained between processes.
- Stop on authentication, access challenges and rate limits. Do not add automatic retries.
