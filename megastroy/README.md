# megastroy

Неофициальный Go CLI для публичного каталога [Мегастроя в Казани](https://kazan.megastroy.com/): поиск, фильтры иерархических категорий и подробная карточка товара. Результаты — JSON в stdout, ошибки — в stderr с ненулевым кодом завершения.

Требуется Go 1.27.2+. Запуск из корня репозитория:

```sh
git clone https://github.com/meoyawn/clis.git
cd clis/megastroy
go run . --help
```

## Доступ к сайту

Аккаунт Мегастроя не нужен, но сайт использует DDoS-Guard. Откройте каталог в Chrome и дождитесь его появления, затем импортируйте анонимные cookie:

```sh
go run . auth import --browser chrome
go run . auth status
```

CLI выполняет обычные HTTP-запросы из Go и не запускает браузер. [Sweetcookie](https://github.com/steipete/sweetcookie) читает существующее хранилище браузера только при `auth import`; macOS может запросить доступ к Keychain. При нескольких профилях используйте `--browser-profile` с именем профиля, директорией или путём к базе cookie.

Сохраняются только разрешённые cookie `__ddg*` домена Мегастроя. Cookie аккаунта, корзины и аналитики не импортируются. Хранилище — `megastroy/auth.json` внутри системной конфигурационной директории, на macOS — `~/Library/Application Support/megastroy/auth.json`; доступ к файлу имеет только владелец. `auth status` показывает локальное состояние без значений cookie и без сетевой проверки.

Хранилище авторизации находится вне репозитория. Не добавляйте в Git реальные cookie, `.env`, HAR-файлы и необработанные браузерные дампы. В тестах используются вымышленные значения cookie и сокращённые публичные страницы без имён и текстов пользовательских отзывов.

Если DDoS-Guard отклоняет запрос, CLI завершает команду без повторных попыток. Обновите страницу в Chrome, дождитесь каталога и снова выполните `auth import`. Cookie могут истечь или перестать приниматься при изменении сети. Для совпадения с необычным браузерным User-Agent есть `--user-agent`.

## Поиск и фильтры

```sh
go run . search полотенцесушитель --include-filters
go run . search полотенцесушитель --category 255 --include-filters
go run . search полотенцесушитель --category 1102 --include-filters
go run . search полотенцесушитель --category 1102 --filter 'field79[]=Terminus'
```

`--include-filters` добавляет данные из той же страницы:

- `categories.path` — предки и выбранная категория; `categories.children` — доступные дочерние категории с количеством товаров.
- `filters` — актуальные фильтры, варианты и выбранные значения. Для диапазона возвращаются `min`, `max`, `from_key`, `to_key`, `from`, `to`.
- `sorting` — варианты сортировки сайта.

В исследованной выдаче путь к водяным полотенцесушителям: `8 → 255 → 1102`. Параметры зависят от выбранной категории и других фильтров: например, ширина `field7[]` в общей категории становится диапазоном `field7[from]` / `field7[to]` в категории водяных полотенцесушителей. Берите ключи и значения из текущего результата, поскольку сайт может их изменить.

```sh
# Несколько значений одного фильтра — повторяйте --filter.
go run . search полотенцесушитель --category 1102 \
  --filter 'field79[]=Terminus' --filter 'field79[]=Сунержа'

# Диапазон цены и сортировка.
go run . search полотенцесушитель --category 1102 \
  --filter 'price[from]=5000' --filter 'price[to]=10000' --sort price

go run . search полотенцесушитель --page 2
```

`--filter field79=Terminus` также принимается как сокращение `field79[]=Terminus`. `--category ID` соответствует `--filter category_id=ID`. Поддерживаются диапазоны `price` и `fieldN`, а также переключатель сайта `in_stock`: `0` скрывает товары под заказ, `1` включает их.

Сортировки: `popular` (по умолчанию), `price`, `price-desc`, `sale`, `latest`, `striked-price`. Страницы CLI начинаются с 1. Для продолжения используйте `next_page`, сохраняя запрос, фильтры и сортировку. Поле `next_url` содержит соответствующую ссылку. CLI не обходит страницы автоматически и не вычисляет общее количество страниц по неполному набору ссылок сайта.

`total` — количество совпадений по данным сайта, `count` — количество возвращённых карточек. `--limit N` обрезает только уже загруженную страницу; переход к следующей странице пропустит и обрезанные карточки. По умолчанию возвращается вся страница. При отсутствии совпадений CLI возвращает пустой `results`, исключая рекомендации, которые сайт может показать вместо выдачи.

Каждая карточка уже содержит `rating` — число закрашенных звёзд из пяти, показанных сайтом, и `review_count` — опубликованное количество отзывов. Отсутствующие значения — `null`. Это видимые звёзды, а не вычисленный средний балл с дробной частью. Для рейтинга CLI не открывает карточки товаров и не делает дополнительных запросов.

## Детали и размеры

```sh
go run . details 416479
go run . details https://kazan.megastroy.com/products/416479
```

`id` и `show` — синонимы `details`. Карточка включает текущую и зачёркнутую цену, подпись цены, единицу продажи, рейтинг и число отзывов, наличие и остатки по магазинам, описание, изображения, документы, категории и все опубликованные характеристики.

`characteristics` сохраняет названия и значения с сайта. `dimensions` отдельно содержит `height_mm`, `width_mm`, `depth_mm`, `length_mm`, `diameter_mm` и исходные характеристики размеров в `properties`. Сантиметры и метры приводятся к миллиметрам только при явно указанной единице. Отсутствующие, неоднозначные или противоречивые данные остаются `null`.

Например, товар `416479` называется «Terminus Классик П6 500х600», но в характеристиках указаны высота **600 мм**, ширина **532 мм** и глубина **84 мм**. CLI берёт размеры из характеристик, а не из названия. Межосевое расстояние и диаметр подключения сохраняются отдельно среди исходных свойств. Поисковые фильтры используют индекс сайта; его значения могут отличаться от габаритов карточки товара.

При проверке 24.10.2026 фильтр высоты `590–610 мм` в категории `1102` вернул пустую выдачу и через форму сайта в Chrome, и через CLI, хотя у товара `416479` указана высота 600 мм. Поэтому пустой результат фильтра размеров не доказывает отсутствие подходящих товаров: для точного подбора проверяйте характеристики через `details`.

## Изображения для просмотра

`search` возвращает URL миниатюры каждой карточки в `images`, а `details` — URL изображений галереи. Эти ссылки берутся из уже полученного HTML без дополнительных запросов.

Чтобы ассистент мог увидеть изображение, скопируйте нужный URL из `images` и выполните:

```sh
go run . image 'URL_ИЗ_IMAGES' --output /tmp/product.jpg
```

Команда скачивает только выбранную картинку за один HTTP-запрос и возвращает JSON с абсолютным `path`, `content_type`, `bytes` и `source_url`. Ассистент может открыть `path` инструментом просмотра локальных изображений. Без `--output` создаётся временный файл; существующий файл не перезаписывается. Для изображений публичного CDN импорт cookie не нужен. Повторного обращения к странице товара нет.

## Количество запросов

| Команда | HTTP-запросы к сайту |
| --- | --- |
| `search`, включая `--include-filters` | не более 1 |
| `details` / `id` / `show` | не более 1 |
| `image` | не более 1, только выбранная картинка |
| `auth import`, `auth status`, `--help` | 0 |

Нет фоновых запросов, автоматических повторов, переходов по HTTP-редиректам, автоматической подгрузки изображений или отдельных запросов для фильтров, размеров и характеристик. Некорректные параметры и отсутствие нужных сохранённых cookie останавливают команду до обращения к сайту. Результаты поиска и деталей содержат `http_requests`, `source_url`, `fetched_at` и `location`.

Общий тайм-аут команды задаётся через `--timeout`, например `--timeout 20s`. Флаги могут стоять до или после позиционных аргументов; `--` завершает разбор флагов. `--json` принимается для совместимости, JSON и так используется по умолчанию.

## Разработка

```sh
go test -race ./...
moon run megastroy:lint
go build -trimpath .
```

Тесты используют локальный HTTP-сервер и сокращённые публичные HTML-страницы в `internal/service/testdata`; они не обращаются к сайту или браузеру. Проверяются категории, изменение фильтров, цены и реальные размеры, пустая выдача с рекомендациями, пагинация, отсутствие повторных запросов и сохранение только анонимных cookie.
